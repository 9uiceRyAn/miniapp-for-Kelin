# 教师账号管理上线

在 backend 环境配置 REGISTRATION_CODE_KEY 为 32 字节随机值的 64 位十六进制字符串。保留该密钥，所有实例使用同一值。不要提交密钥。

上线前备份数据库和 backend，确认已有可用教师账号。运行 npm run migrate，然后运行 node scripts/init-registration-codes.js 初始化两个随机共享码，再切换后端。旧环境变量注册码在新版本中立即失效。

教师登录微信小程序后，打开「我的」→「教师管理」，即可管理师生账号、教师码和学生码。普通教师也可使用该入口。两码均永久有效且不限人数。新码要求 6–72 位、首尾无空格，教师码与学生码不同。保存时校验版本，冲突后刷新页面。

检查普通注册和微信注册的新旧码行为、学生访问被拒绝、小程序保存后重新进入能看到修改，以及停用和重置密码撤销会话。恢复旧后端会恢复旧环境注册码，应在维护窗口进行回滚。
