# 第二期：Agent 小程序页面与带题提问

## 设计基线

沿用[共用原生 UI 基线](../01-shared-foundation.md)。教师管理与学生使用均在小程序内完成，保留第一期已交付的题库页面。

使用“教学助手”“创建助手”“资料来源”“费用统计”等用户可理解的名称，内部 Run/Provider/SkillRevision ID 不作为主要界面内容。

## 页面与入口

具体页面路径是实现约定，导航名称可以在不改变功能的前提下微调。

本期增加教学助手、带题提问、教师 Agent 管理和平台模型/费用页面。

| 页面 | 功能 |
| --- | --- |
| 现有首页 | 保留资料与题库入口，增加教学助手入口 |
| 已有题目详情 | 增加带题提问操作，原浏览功能保持独立 |
| 教学助手列表 / 详情 | 已发布 Agent、教师、教学用途、开始对话 |
| 学生会话 / 历史 | 消息、附件、引用、工具进度、取消与恢复 |
| 教师“我的 Agent” | 草稿、已发布版本、修改与发布 |
| 创建助手 / 草稿预览 | 对话生成 Skill、公共教学资料、教学模型选择 |
| 教师试聊 | 明确试聊状态与使用的草稿版本 |
| 学生使用记录 | 自己 Agent 下的学生、费用、完整对话和作业 |
| 平台管理 | 仅指定管理员可见的模型目录、连接配置与费用监控 |

教师界面不出现工具勾选列表。学生界面不出现 API Key 表单或模型切换控件。模型由教师选择并随 Agent 版本固定。

## 创建与发布

创建页面首先让教师描述目标，可以添加公共教学材料。创建助手生成内容后展示名称、简介、教学指令摘要、资料来源和教学模型。

教师可以继续对话修改、展开查看生成内容、启动试聊和发布。草稿保存、试聊与发布状态明确区分；模型生成完成不等于已发布。

“上传教学资料”说明该资料将加入公共库供所有 Agent 检索；上传处理中的状态可见，解析失败应允许用户修正或重试。

## 学生会话

- 支持文字、图片、PDF、DOCX，附件显示上传与解析状态。
- 使用既有小程序文件选择能力：拍照/相册和微信聊天文件等，不承诺任意系统文件浏览器。
- 回答支持段落、列表、数学公式、题图和资料引用，长作文可阅读与滚动。
- 生成中显示真实工具进度，例如“正在检索题库”“正在读取第 3 页”。
- 取消按钮在服务端返回 Run ID 后即可用。
- 离开页面、重新进入或短暂断连后恢复同一运行和历史，不重复创建消息。
- 引用卡片显示来源、题号/页码以及相应修订；打开历史引用不悄悄替换为最新版。
- 新会话保持独立；历史列表允许继续原会话。
- 显示该 Agent 的教师可查看会话和提交作业。

## 带题提问

1. 用户在已交付题目详情选择“用教学助手讲解”。
2. 选择已发布 Agent，保留选中题目的 ID 与当前 revisionId。
3. 创建会话或进入明确选择的已有会话；发送前显示题目引用卡片，允许补充问题。
4. 服务端按 ID 和 revisionId 读取真实题目上下文与媒体，不信任客户端提交的题干正文或任意 URL。
5. 消息保存所选修订，回答可引用它；Agent 后续主动检索其他公共资料时使用最新可用修订。

如果所选修订已不可读取，明确提示，由用户选择最新版，不能在发送途中静默替换题目。底层读取契约沿用[一期题库 API](../phase-1-question-bank/01-data-and-api.md)，回答引用规则见[资料与工具](02-public-library-and-tools.md)。

## 费用与教师记录

教师可以按自己的 Agent、学生和时间查看使用及费用，进入学生完整会话并查看其作业。管理员查看平台范围；学生只查看自己的使用信息。

费用页面显示已知费用、估算/待核实状态和币种。界面不展示费用额度进度条、剩余次数或“超额停用”。

## 必须验证的显示状态

空列表、加载、无检索结果、文件解析失败、模型失败、取消、连接恢复、资料原文不可用、费用待核实均有明确状态。验证手机键盘与底部输入区域、长公式/长文本、桌面宽屏和引用导航返回位置。

开发者工具编译、桌面预览和真机验证均属于交付验收，不能只凭 WXML/WXSS 静态检查宣称完成 UI 对齐。
