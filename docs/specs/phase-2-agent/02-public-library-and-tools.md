# 第二期：公共资料库、工具与引用

## 接入边界

复用第一期已交付的[题库查询与资源读取](../phase-1-question-bank/01-data-and-api.md)，在 Kelin 既有文件库上增加教学文档提取、片段定位和公共搜索。现状证据统一保存在[共用约定](../01-shared-foundation.md)。

教师上传 PDF/DOCX 后可以形成可检索正文，但正文提取不等于已生成经过验证的结构化题目，不自动把文件拆成正式题库条目。

## 公共与私有内容

- 教师提交为教学知识材料的文件加入公共资料库，可供所有 Agent 检索。
- 已有公共题库和现有 Kelin 公共文件统一提供检索入口。
- 学生作业、学生会话附件、教师创建助手聊天记录是各自业务记录，不自动公开入库。
- 工具默认全部可用不等于绕过资源权限。公共资料可共享，私有作业仍按会话与教师所属关系鉴权。
- 文件上传、解析和入库状态分别展示；只有可用修订被检索。

实现约定：教学资料成功提交并解析完成后进入公共索引，不以某个 Agent 的发布作为检索权限开关。小程序上传入口应明确“公共教学资料”与“本次对话附件”的区别。

## 文档修订

教学文件采用[共用资源身份与修订规则](../01-shared-foundation.md)，保留 `files.id` 和原始文件关系。新增正文片段、页码/段落位置与解析状态；当前检索指向最新可用修订。

撤下资料后不继续作为当前资料检索。回答保留原来源、修订和位置；原文已删除时明确显示不可用，不能把历史引用悄悄指向新内容。

## 查询契约

实现约定：先复用已有结构化字段与普通数据库检索。所选索引必须能支持中文、学科标签、题号和文档正文；数据库全文能力是否足够由实际数据样例验证，不在本轮增加未经验证的向量数据库依赖。

查询至少支持：

- 资料类型、学科、数据集、关键词、标签、审核状态和分页；
- 题目 ID/题号与来源信息；
- 文档正文片段及页码或段落定位；
- 题目图片、答案材料和音频的原始角色。

搜索结果必须带真实资料 ID、修订、标题、命中片段或题目摘要。空结果与解析失败可区分；工具不能把模型生成的摘要伪装成已命中的原文。

## 平台工具

所有已上线、可执行的平台教学工具默认向教学 Agent 提供，不保存教师勾选的工具白名单。管理员管理模型、密钥、发布权限和文件删除属于业务接口，不作为“默认教学工具”暴露给模型。

以下工具名为迁移实现约定，可适配现有名称：

| 能力 | 最低真实行为 |
| --- | --- |
| `search_questions` | 查询正式题目索引，返回真实题目 ID、修订、摘要与媒体引用 |
| `get_question_image` | 按题目和修订读取题图/答案图，保留图片角色 |
| `search_library` | 查询公共教学资料正文与标签，返回定位片段 |
| `read_library_resource` | 读取指定资料修订及指定页/片段 |
| `parse_file` | 解析当前用户获准访问的 PDF、DOCX 或附件 |
| `read_image_text` | 对获准访问的图片执行真实识别 |
| `calculate` | 执行明确的数学运算并返回结果；不接受任意脚本 |
| `web_search` | 若作为平台已上线工具，使用已配置搜索服务并返回真实网页来源 |

工具必须有各自的参数 schema、执行函数、结果格式和错误语义。工具描述不等于实现；返回 `query` 与题库名称不能作为检索成功。

尚未配置执行服务的能力标记为平台不可用，不伪装成正常工具。这是全平台运行状态，不是教师逐项启停工具。模型是否支持所需工具调用和输入能力应在模型目录中验证。

执行上下文由服务端注入真实用户、会话、Agent 版本和 Run，不接受模型通过参数伪造。文件和题目使用业务 ID，工具不读取模型指定的任意本地路径。

## 引用与最新资料策略

每次检索读取执行时最新可用的资料修订。工具读取检索结果时必须使用结果中返回的修订 ID，避免检索与读取之间发生内容替换。

记录两层信息：

1. 工具调用记录保存实际检索/读取到的资源及修订。
2. 回答 Citation 保存实际用于支撑回答的来源、修订、题号/页码/片段位置。

客户端来源卡片通过 Citation 打开当时的资料修订；“查看最新版”是单独的导航。引用必须能关联到实际工具结果或本条消息明确附带的题目/材料，不能只保存模型输出的一个来源名称。

资料检索更新不会修改旧回答及其历史引用。“带题提问”固定选中条目的交互与接口约定见[Agent 小程序页面](05-mini-program.md)。
