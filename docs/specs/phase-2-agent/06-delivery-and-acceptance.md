# 第二期：Agent 实施与验收

状态：完整应用开发版已实现；见 [实施说明](../02-complete-implementation.md) 与 [验证记录](../VALIDATION.md)。启动条件为样本题库服务通过，正式全量数据验收独立跟进。

## 实现顺序

| 步骤 | 工作 | 完成条件 |
| --- | --- | --- |
| 1. 运行环境与后端 | 验证锁定 Mastra/AI SDK、CommonJS/ESM 边界；在同一后端接入真实身份、模型与 Agent 数据 | 同一服务启动，平台模型可用，既有题库不受影响 |
| 2. 资料与工具 | 解析公共教学文档，连接一期题库与资源服务，落实工具真实执行和引用 | 工具返回真实资料/媒体与修订，私有附件不进入公共检索 |
| 3. 创建与教学 | 创建助手生成 Skill、试聊/发布、学生多格式输入、版本/事件/取消/恢复、带题提问 | 三类教学角色由配置承载，端到端流程可用 |
| 4. 教师记录与费用 | 完整学生记录、模型计量与费用展示、原生 UI | 所有者权限正确、费用可追溯，整体验收通过 |

计量基础从模型调用接入时建立，费用展示在最后完成；不能漏计创建助手和试聊阶段的实际调用。

## 验收矩阵

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| AG-01 | 创建答疑、批改、辅导角色 | 共用配置与运行系统，不另建三套固定后端 |
| AG-02 | 创建助手修改草稿 | 已发布版本和旧学生会话不变，发布由教师触发 |
| AG-03 | 教师试聊后修改草稿 | 已开试聊保持原快照，新试聊采用新快照 |
| AG-04 | 教师发布新版本并换模型 | 旧会话沿用原配置，新会话使用新配置，学生不能换模型 |
| AG-05 | 同一学生开启两个会话 | 新会话不注入旧会话内容，历史会话仍可继续 |
| AG-06 | 文字/图片/PDF/DOCX 输入 | 实际进入处理链路，扫描/解析失败明确可见 |
| AG-07 | 检索、题图、文件和计算等工具 | 返回真实执行结果，不以 query 和题库摘要充当检索结果 |
| AG-08 | 教师提交公共资料，学生提交私有作业 | 可用教学资料供所有 Agent 检索，私有作业不可被公共检索命中 |
| AG-09 | 公共资料从 r1 更新到 r2 | 新检索得到 r2，旧回答仍指向实际使用的 r1 |
| AG-10 | 选中题目 r1 后资料更新 | 带题消息保持 r1，或明确提示不可用，不静默换成 r2 |
| AG-11 | 教师查看自己/其他教师 Agent 下的学生记录 | 自己 Agent 的明细、完整对话和作业可见；其他教师范围被拒绝 |
| AG-12 | 普通教师/学生请求平台模型秘密 | 不返回密钥；只有指定管理员可维护连接与价格 |
| AG-13 | 双击发送、请求重试、事件重放 | 消息、Run、费用幂等，不混入其他轮次消息 |
| AG-14 | 工具耗时、取消、断连、重启 | Run ID 及时可得，进度真实，终态明确，记录可恢复 |
| AG-15 | 创建助手、试聊、多步骤学生调用、失败调用 | 按真实使用人和用途计量，已知费用保留，缺失用量不记零 |
| AG-16 | 价格变更、多币种、累计费用升高 | 历史价格快照保留，币种不混加，不因累计费用拦截 |
| AG-17 | 手机/桌面长作文、公式、题图、引用与输入 | 可读可操作，键盘/底部输入正确，符合 Kelin 品牌 |
| AG-18 | 接入 Agent 后回归一期 | `QB-*` 仍通过；模型服务故障不影响独立题库浏览 |

## 验证与交付证据

- API/数据库集成验证覆盖身份、所有者关系、幂等、版本与引用。
- 模型联调验证真实工具调用、文档读取和引用归属，不要求模型回答文字完全一致。
- 费用记录覆盖多步骤、取消、失败、缺失计量和价格修订。
- 小程序保留开发者工具、桌面、真机关键流程证据；语法检查不替代这些验收。
- 部署文档与实际构建、Node.js 版本、迁移和启动方式一致；按既有要求备份并保留生产 `.env`。

## 本期接入参数

- 目标 Node.js 环境与 TypeScript/ESM 接入方式，见[后端规格](04-backend-and-api.md)。
- 平台供应商、模型 ID、密钥、指定管理员、币种和单价。
- 文件解析服务、文件大小/页数与上下文处理边界。
- 小程序增量传输、媒体鉴权及 Nginx 超时/缓冲的实际兼容性。
- 原 Agent 服务的真实业务数据是否迁移；没有实际清单时不自动导入 demo 用户与会话。

本期不额外加入费用额度、跨会话记忆、学生自带密钥、教师工具勾选或第二套后端部署。
