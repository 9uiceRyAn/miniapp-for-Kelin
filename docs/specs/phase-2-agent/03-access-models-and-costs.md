# 第二期：权限、模型与费用

题库基础身份与数据关系沿用[共用约定](../01-shared-foundation.md)。本文件只定义第二期新增的 Agent 权限、模型和费用行为。

## 身份与业务权限

使用现有 Bearer session 和 `users.id`。指定管理员采用增量能力授权，不改变既有 `teacher` / `student` 对文件 API 的含义，也不自动让所有教师成为管理员。

| 操作 | 学生 | 教师 | 指定平台管理员 |
| --- | --- | --- | --- |
| 浏览公共题库与资料 | 可以 | 可以 | 按其账号现有业务权限 |
| 使用已发布 Agent | 可以 | 可用于验证教学效果 | 按其账号业务权限 |
| 创建、修改、发布 Agent | 不可以 | 仅自己的 Agent | 不因管理员身份自动取得内容所有权 |
| 选择教学 Agent 模型 | 不可以 | 自己 Agent 的平台可选模型 | 维护可选目录 |
| 查看会话与作业 | 仅自己的 | 自己会话，以及自己 Agent 的学生会话和作业 | 默认仅运行/费用元数据；不附带全部会话正文权限 |
| 查看学生明细与费用 | 自己使用情况 | 自己 Agent 下的明细 | 平台费用与计量明细 |
| 管理模型连接、密钥和价格 | 不可以 | 普通教师不可以 | 可以 |

教师查看学生会话时必须同时验证教师是该 Agent 的所有者、会话确属该 Agent、会话模式为学生使用。不能只校验 `role === teacher` 后允许读取所有会话。

学生作业不会进入公共知识库。教师查看作业通过受保护的附件接口完成。学生对话页面应清楚说明该 Agent 的教师可以查看会话和作业，作为已确认教学管理功能的说明。

## 平台模型目录

管理员维护模型连接、模型标识、展示名称、可用状态、支持的输入/工具能力和价格。教师只能从已启用目录中选择。

模型目录与密钥分离：

- 教师和学生响应不返回 API Key 或完整连接秘密。
- 发布快照固定模型身份及推理参数；实际调用记录解析后的具体模型。
- 平台密钥轮换不要求教师重新发布。
- 禁用模型或供应商故障不静默改用其他模型。
- 现有 caller-owned provider 逻辑必须改为服务器读取平台模型连接，不能继续要求学生配置密钥。

平台模型需要覆盖本期文字、图片、文档解析后的内容及工具调用。目录中的能力字段必须通过实际调用验证，不以模型显示名称推断。

## 费用监控

产品规则：平台付费，只监控，不设置费用额度、不阻止超额使用、不显示“剩余额度”。

统计维度至少包含：

- 实际使用人、Agent 与版本、模型、时间；
- 用途：创建助手、教师试聊、学生会话；
- 输入/输出及供应商支持的缓存等计量分类；
- 实际使用价格版本、币种、费用状态。

学生会话费用归属实际学生，不归到 Agent 作者名下。教师创建和试聊归属教师。教师视图按自己 Agent 聚合，管理员可查看平台全量费用。

每个有计费结果的模型步骤或外部计费操作分别记录；一轮 Agent 中多次模型调用和有费用的 OCR/解析/搜索服务不能只统计最后一次回复。

## 费用计算与完整性

实现约定：

- 价格采用管理员配置的带生效时间快照，费用使用十进制定点精度。
- 按供应商返回的计量类别分别核算，避免缓存 token 与普通输入重复计费。
- 没有供应商实际账单时，按计量与价格计算的金额展示为“估算费用”。
- 缺失用量、价格或币种时记录“待核实/未定价”，不能记为零成本。
- 失败、取消或中断仍可能产生费用，保留已知计量并标记不完整部分。
- 多币种分开汇总；未配置换算规则时不直接相加。
- 调整价格不覆盖历史价格快照，事件重放和请求重试不重复记账。
- 不在日志、事件或导出的费用记录中输出 API Key。

技术性的执行超时、上下文大小和文件大小约束用于保证处理正确，不得转化为未获确认的每日调用次数或费用额度规则。
