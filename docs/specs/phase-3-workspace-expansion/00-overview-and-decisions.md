# 第三期：工作台能力扩展 — 总览与已确认决策

更新：2026-11-26。状态：产品决策已确认，待规格评审后分期实施（当前为待实现规格，不改变现有代码与生产基线）。

## 1. 背景与目标

基于现有 v0.1 文件管理与一、二期学习平台（题库 + 教学 Agent）基线，补齐以下四项核心工作台能力：

1. **网盘式资料管理**：以自由多级文件夹树替代当前「资料」Tab 首页，支持师生共同上传/整理文件、个人标记、回收站防误删，以及常见文档自动建轻量文本索引供 AI 检索。
2. **AI Agent 预设管理中心**：升级现有 `studio` 为极简管理中心，仅保留名称、简介、一段话 Prompt 与工具权限（只读 / 可改），支持启停与管理员全局置顶/排序。
3. **题库管理增强与题库整理 AI 助手**：向教师开放与管理员同等的题库管理权限，补齐可视化分类与标签树管理、批量操作、拍照/PDF 智能录题，并内置系统预设「题库整理 AI 助手」（写操作需卡片确认）。
4. **移除独立 `admin` 权限，统一共享管理员密码门禁**：系统只保留 `student` / `teacher` 两种账号角色，移除原有的 `kl_capabilities` 独立 `admin` 权限判断；所有教师拥有同等的教学与内容管理权限，而「账号管理」与「平台与 API 管理」两个敏感管理界面统一通过同一个**共享管理员密码**解锁访问。

## 2. 已确认产品决策（D21–D41）

| 编号 | 主题 | 已确认决策 |
| --- | --- | --- |
| D21 | 网盘目录形态 | 采用自由多级文件夹树（支持新建、重命名、移动文件夹与文件），直接替代现有「资料」Tab 首页。 |
| D22 | 网盘权限与防误删 | 公共共享网盘：学生可上传文件、新建目录，但仅可重命名/移动/删除自己创建的文件夹与文件；教师可管理全部内容；引入回收站（软删除 + 恢复 + 教师彻底清理）防止误删。 |
| D23 | 网盘底层存储与上传 | 继续沿用服务器本地磁盘存储（`UPLOAD_ROOT`），单文件上限保持 `MAX_UPLOAD_MB`（默认 200MB）；桌面端直接选文件，手机端沿用相册/拍照/微信聊天文件。 |
| D24 | 旧数据自动迁移 | 通过增量 migration 将 v0.1 `files` 表的 `A–E` 分类自动映射为网盘根目录下的 5 个默认文件夹，保留原 `files.id`、物理文件与 `user_file_marks` 个人标记；已有公共教学文档（`kl_resources`）同步挂入网盘并保持原 `resourceId` 可用。 |
| D25 | 网盘与 AI 联动 | 上传常见文档（PDF / Word / TXT / Markdown / 图片）自动在后台触发轻量文本提取与分段索引，供 AI 检索；视频/压缩包/其他二进制文件仅作网盘存储不建索引。原「教学资料管家」不再独占资料 Tab，收进网盘角落入口或下线。 |
| D26 | Agent 预设管理中心 | 升级现有 `studio`（教师工作台）为独立的「AI Agent 预设管理」中心并提供明确入口；保持极简，教师创建并启用的 Agent 对所有已登录用户可见，不做复杂按学生/班级划分的 ACL。 |
| D27 | Agent 极简配置项 | 编辑一个 Agent 仅保留 5 项：**名称**、**简介**、**一段话 Prompt**、**工具权限（`只读` / `可改`）**、**可用范围（`所有人可用` / `仅教师可用`）**；去掉开场白、推荐问题、工具使用说明、温度参数、单文件引用、独立选模型与创建助手对话编写。 |
| D28 | 初始预置与管理权限 | 初始化预置 3 个开箱即用 Agent（通用学习答疑助手、英语写作批改助手、题库整理助手），**行为与普通 Agent 完全一致**，可正常编辑、启停、置顶或删除，无需恢复默认功能；`可改` 权限仅对教师生效（学生对话自动降级为只读，修改已有数据仍需卡片确认）。 |
| D29 | 题库管理权限 | 所有教师拥有完全相同的题库管理权限（进入题库管理页、增删改题、分类管理、批量操作、导入及使用题库整理 AI 助手）。 |
| D30 | 题库分类体系管理 | 支持可视化增删改学科（Subjects）、数据集（Collections）与知识点标签树（Taxonomy Tags），取代当前只能读已有 facets 与手敲 `编号 \| 名称` 纯文本的方式。 |
| D31 | 题库批量操作 | 支持多选题目进行批量发布、转为草稿、设为暂定发布、审核通过/取消待审核、批量增删标签、批量删除/恢复。 |
| D32 | AI 辅助录题与解析 | 支持拍照/上传图片或 PDF，调用视觉/文本模型自动切题、识别题干与参考答案、推荐知识点标签，生成待确认草稿列表后再落库。 |
| D33 | 系统预设「题库整理 AI 助手」 | 内置系统级 AI 助手辅助整理题库（查题、质检、查重、补标签、生成待导入草稿）；查询、分析与生成新题草稿可直接执行，但修改或删除已有题目必须生成操作确认卡片，经教师点击确认后才落库。 |
| D34 | 共享管理员密码门禁 | 「账号管理」（`pages/accounts`）与「平台与 API 管理」（`pages/admin`）共用同一套**共享管理员密码**（`ADMIN_MANAGEMENT_PASSWORD_HASH`，兼容旧 `MODEL_MANAGEMENT_PASSWORD_HASH`），一次解锁 15 分钟内可访问这两个敏感管理界面。 |
| D35 | 推荐交付顺序 | 建议按独立度与依赖顺序分四步交付：Step 0（账号管理密码门禁）→ 期 1（网盘式资料管理）→ 期 2（AI Agent 预设管理中心）→ 期 3（题库管理增强 + 题库整理 AI 助手）。 |
| D36 | 视觉主色调 | 全站以极简黑白灰为主（`#ffffff` 白底、`#242424` 炭黑主色、`#e9e9e9` 极细边框）；COLLINS 酒红 `#9B1F58` 仅保留用于 Logo 与品牌标识。 |
| D37 | 两套页面外框 | 主 Tab（聊天/题库/资料/我的）用 `.workspace-shell`（带侧栏与底栏）；二级管理页（账号/平台/Agent 预设/题库管理）统一用轻量子页外框 `.subpage-shell`（统一顶栏返回，不带底栏）。 |
| D38 | 抽屉弹窗编辑范式 | 全站所有新建、编辑、移动与配置表单一律使用统一的抽屉弹窗（Sheet），桌面端右侧滑出、移动端底部弹出，尽量不跳页。 |
| D39 | 旧页收口范围 | 随第三期开发一并将 `accounts`、`admin`、`studio`、`home` 收口到同一套公共 Token 与组件样式体系。 |
| D40 | 移除独立 `admin` 权限 | 系统仅保留 `student` 与 `teacher` 两种账号角色，移除原有的 `kl_capabilities` 独立 `admin` 权限判断及页面上的「平台管理员」徽标；将「我的」里的「API 管理」与「平台管理」合并为单一「平台与 API 管理」入口。 |
| D41 | 全模型默认视觉与管理界面重设计 | 所有新接入与存量模型默认启用视觉能力（`vision: true`, `tools: true`），移除添加模型时冗余的能力开关；重设计 `pages/admin`（「列表 + `.ws-sheet` 抽屉」），合并多颗灰块测试/设置按钮为单一「测试连接」与「⋯」菜单（详见 [04-ui-design-system.md](04-ui-design-system.md#51-平台与-api-管理pagesadmin重设计规范)）。 |

## 3. 统一权限矩阵

| 模块 / 操作 | 学生 (`student`) | 教师 (`teacher`) | 教师 + 共享管理员密码已解锁 |
| --- | --- | --- | --- |
| 网盘：浏览、下载、ZIP 导出、个人标记 | 允许 | 允许 | 允许 |
| 网盘：上传文件、新建文件夹 | 允许 | 允许 | 允许 |
| 网盘：重命名/移动/软删除自己创建的项 | 允许 | 允许 | 允许 |
| 网盘：重命名/移动/软删除他人创建的项 | 拒绝 (403) | 允许 | 允许 |
| 网盘：回收站恢复自己的项 | 允许 | 允许 | 允许 |
| 网盘：回收站恢复任意项 / 彻底清理 | 拒绝 (403) | 允许 | 允许 |
| AI Agent：使用对当前角色可见且已启用的助手对话 | 仅 `所有人可用` | 全部 | 全部 |
| AI Agent：创建/编辑/启停/置顶/排序/删除助手 | 拒绝 (403) | 允许 | 允许 |
| 题库管理：列表/增删改/分类管理/批量/导入 | 拒绝 (403) | 允许 | 允许 |
| 题库整理 AI 助手（含卡片确认） | 拒绝 (403) | 允许 | 允许 |
| 账号管理（`pages/accounts`） | 拒绝 (403) | 需解锁 (403) | 允许 |
| 平台与 API 管理（`pages/admin`，含模型/价格/全平台费用） | 拒绝 (403) | 需解锁 (403) | 允许 |

## 4. 数据库增量 Migration 规划

所有 schema 变更继续遵循 [agent.md](../../../agent.md) 规范，通过 `database/migrations/` 下有序增量 SQL 脚本完成，保持向后兼容与 v0.1 主键契约：

1. `006_cloud_drive.sql`：新增 `drive_folders` 表；为 `files` 表增量添加 `folder_id`、`deleted_at`、`deleted_by`、`ai_resource_id`、`ai_index_status`、`ai_index_error`；自动迁移 `A–E` 分类为根目录文件夹，并将已有公共 `kl_resources` 挂入网盘。
2. `007_agent_presets.sql`：为 `kl_agents` 增量添加 `tool_permission`（`read_only` / `read_write`）、`audience`（`all` / `teacher_only`）、`preset_key`、`enabled`、`pinned`、`sort_order`，并预置 3 个初始 Agent。
3. `008_question_taxonomy_and_curator.sql`：新增 `kl_subjects`、`kl_collections`、`kl_taxonomy_tags` 并从现有 `kl_revisions` / `kl_tags` 回填初始分类与标签树；支持题库整理 AI 助手会话与确认动作记录。
