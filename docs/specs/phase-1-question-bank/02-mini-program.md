# 第一期：题库小程序页面

## 用户流程与范围

登录 Kelin → 首页“题库”入口 → 学科/数据集/关键词筛选 → 查看条目和关联材料。

本期独立完成题库浏览，不要求模型服务。使用[共用 UI 基线](../01-shared-foundation.md)，保留原资料首页、A–E 分类、文件搜索和个人 marks。

“用教学助手讲解”及带题进入对话在[第二期小程序规格](../phase-2-agent/05-mini-program.md)定义，本期不展示不可用的 Agent 操作。

## 页面

| 页面 | 核心内容 |
| --- | --- |
| 现有首页 | 增加题库入口，保留原资料功能 |
| 题库列表 | 学科、数据集、已有标签/技能、关键词、分页和结果数量 |
| 题目详情 | 题图、标题、标签、来源、质量状态、答案/原文/插页与音频 |

具体原生页面路径是实现约定，不影响上述流程。

## 列表与筛选

- 卡片显示标题、学科/数据集、主标签、可用缩略图和实际质量状态。
- 学科与数据集可跨库浏览，具体标签使用选中数据集的 taxonomy。
- 条件变化重置分页，支持清除条件、加载更多和无结果状态。
- 结果数量由服务端返回；题组、整卷和听力材料显示真实名称，不一律称为单题。
- 无缩略图时保留标题和来源；待审核或 provisional 内容不标成已验证答案。

字段及筛选作用域只在[题库数据与 API](01-data-and-api.md)维护。

## 详情与媒体

按数据契约中的 `gallery.kind` 展示题目、原文、答案及插页，保留原 label。答案材料与题图区分；没有答案时显示“暂无答案材料”，不补造标准答案。

有音频时提供原生播放和基本控制，切换条目、离开页面时正确处理播放状态。界面按实际可用信息显示，不假定存在转写、时间戳或统一时长。

显示来源与所读资料修订；指定修订不可用时明确提示。媒体交给后端生成访问引用，小程序不拼接服务器路径。

## 状态与设备表现

覆盖列表/详情加载、无结果、缺少题图、无答案、媒体加载失败、登录失效、资料修订不可用。

手机端使用可阅读的卡片与图片查看交互；桌面端沿用现有宽屏布局习惯。验证长标题、来源文字、多图滚动、音频播放以及返回列表后的筛选状态。

本期不增加题目收藏、错题本、做题记录、掌握度或智能推荐。原文件 marks 仍只属于原文件业务，不作为全局题目属性。
