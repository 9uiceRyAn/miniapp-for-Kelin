# 产品范围与已确认决策

## 目标与交付顺序

先把现有题库接入 Kelin 原生小程序并独立验收，再加入可配置的教学 Agent。两期共用现有登录、后端与资料身份。

| 交付期 | 用户获得的能力 | 实施入口 |
| --- | --- | --- |
| 第一期：题库 | 浏览和筛选正式题库，查看题图、来源、答案材料及已有音频 | [题库实施与验收](phase-1-question-bank/03-delivery-and-acceptance.md) |
| 第二期：Agent | 教师创建发布，学生多格式对话，带题提问，教师查看记录和费用 | [Agent 实施与验收](phase-2-agent/06-delivery-and-acceptance.md) |

第一期完成条件不包含模型或 Agent 运行时。第二期的拍题答疑、作文批改和知识点辅导由不同角色配置承载，共用创建、发布、会话和工具机制。

## 用户流程

### 第一期

登录 → 进入题库 → 筛选条目 → 查看题目和关联材料。教师、学生均沿用原账号，现有 A–E 资料与个人 marks 保留。详见[题库页面](phase-1-question-bank/02-mini-program.md)。

### 第二期

- 教师：与创建助手描述教学目标、提交公共教学材料 → 查看和修改 Skill 草稿 → 选择模型、试聊 → 发布 → 查看自己 Agent 的学生记录。
- 学生：选择已发布 Agent 或从题目进入 → 提交问题/作业 → 查看回答和来源 → 继续会话或查看历史。
- 管理员：维护平台模型连接、目录和价格，查看平台费用；需要显式授权。

页面交互见[Agent 小程序规格](phase-2-agent/05-mini-program.md)，权限范围见[权限与费用](phase-2-agent/03-access-models-and-costs.md)。

## 范围边界

这两期不增加独立 Vue 管理台、学生自带密钥、代码沙箱、跨会话学习档案、班级分配或费用额度拦截。第一期不额外增加错题本、做题记录、收藏、推荐或以图搜题。

题库已有音频播放属于第一期；学生上传音频不在已确认输入格式中。

Agent 版本固定与公共资料实时检索是两个独立规则，分别由[运行时](phase-2-agent/01-authoring-and-runtime.md)和[资料引用](phase-2-agent/02-public-library-and-tools.md)定义。旧会话可沿用原教学指令，同时引用新资料；每次回答需可追溯到实际配置和资料修订。

## 2026-10-28 补充决策

本轮交付覆盖完整应用。题库与 Agent 是实现先后关系，代表性样本题库服务通过后即可继续 Agent，不以正式全量分类冻结作为开发前置条件。供应商管理采用 LiteLLM 内部网关及独立 PostgreSQL，小程序继续只访问 Kelin。正式全量数据验收仍需分类侧最终交付。
